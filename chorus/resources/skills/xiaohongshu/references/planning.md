# 小红书选题

供 idea 角色挑选适合做成一组竖版图文笔记的切入点。用户已给定的主题、角度和数量优先。

## 选题标准

候选应能在首图和首两行内说清“这篇对谁有用、能带走什么”，并适合拆成连续滑读的信息卡：

- 有明确人群、场景、问题或结果，不是泛泛观点。
- 能自然组织成步骤、清单、前后对比、避坑或案例，而不是长篇论述。
- 读者滑完能带走一个判断、做法或可保存的清单。

避免把资讯标题改写成笔记、只抒情不提供信息，或用无法验证的夸张承诺制造点击。

## 默认规模

- 候选：3-5 个。
- 标题：每个候选给一个 12-20 字的标题，关键词和核心收益靠前；不得超过 20 个汉字等效字符。
- 图文：默认 4-9 张，按“封面 → 核心内容 → 示例/细节 → 总结或行动”组织；用户指定 `image_count` 时以其为准。
- 正文：默认 200-600 字，以短段和自然换行为主；不依赖列表或其它 Markdown 富文本排版。
- 标签：3-5 个，使用具体可检索的主题词。

这些是未指定时的平台默认值，不要覆盖创作意图里的明确要求。标题、视角和理由的 Markdown 格式遵循 system prompt。
