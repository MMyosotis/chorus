# 小红书成品装配

供 finalize 角色把前置产物装配成可预览的小红书图文笔记。front matter 写法和正文结构约束由 system prompt 规定，本文件只给内容取舍与资源路径。

## 装配来源

- 标题使用 idea 产物中已选定的候选，写入 front matter 的 `title` 字段，不另起，也不写成正文的 `#` 一级标题；再次检查标题不超过 20 个汉字等效字符。
- 正文保留 script 产物中的短段和收束问题，只做装配所需的排列；不要重新扩写成长文，也不要改造成列表、引用或其它富文本块。
- 成品只保留开头的一组 front matter；不要把 script 产物自身的 front matter 再写进正文。
- 第一张图作为封面，后续图片按其语义插入相关文案之后，形成连续滑读节奏，不要把全部图片堆在开头或末尾。
- 从主题和正文提炼 3-5 个具体标签写入 `tags`。标签字段只写词本身，不加 `#`，预览模板会显示井号。

## 排版取舍

- 成品以小红书网页端左右分栏的图文笔记详情预览呈现；正文保持扁平的短段文本，段落与图片之间留有自然间隔。
- Markdown 只保留正文换行和图片语法；不加入标题、列表、引用、表格、强调、分隔线或其它可见富文本格式。
- 不把“点赞、收藏、评论”等互动数据写成真实事实；预览中的数字仅是界面装饰。

## 成品资源

front matter 中的资源引用原样写入本包预览路径：

- `preview_ref: xiaohongshu/preview/desktop.html`
- `stylesheet_ref: xiaohongshu/preview/desktop.css`

不读取或复述 preview 文件内容；资源由前端根据这两条引用加载。
