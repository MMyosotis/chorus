# 小红书配图规则

供 image 角色生成可连续滑读的图文笔记配图。图片数量以创作意图的 `image_count` 为准。

## 规格

- 以竖图为主，统一使用 3:4（推荐 1080×1440）构图；封面和内页保持同一色调、字体气质和版式语言。
- 第一张是封面：主体、核心结果或场景一眼可见，留出标题安全区；它负责让人理解主题，不承担完整正文。
- 后续图片按信息顺序推进，可分别承担步骤、清单、细节、例子或总结，不要每张都重复同一句卖点。
- 主体清晰、层级简洁、四周保留安全边距，避免把关键信息贴在边缘而被信息流裁切。
- 尽量不生成长段文字；必须出现文字时仅保留一条短标题或关键词，确保可读且不依赖图片文字传达全部事实。

## 图注

每张配图写一句 caption，说明它展示的内容和对应正文位置。首图 caption 要说明封面主题，内页 caption 要能对应一个具体信息点。工具调用、URL 和失败处理遵循 system prompt。
