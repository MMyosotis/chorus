# 网页博客选题

供 idea 角色挑选能展开为网页长文的切入点。用户已给定的主题、角度和数量优先。

## 选题标准

候选应适合展开为 800-1500 字、3-5 个小节的长文：

- 有足够的信息可供展开，不是一句话就能说完。
- 能自然分成步骤、对比、清单或递进小节。
- 读者读完能带走方法、认知或可执行清单。

避免只有情绪没有信息、只能转述资讯，或无法支撑长文结构的切入。

## 默认规模

- 候选：3-5 个。
- 正文：3-5 个小节，每节 1-3 个段落。
- 配图：1-3 张，教程和步骤类倾向多配，观点类倾向少配。
- 标签：2-4 个。

这些是未指定时的平台默认值，不要覆盖创作意图里的明确要求。标题、视角和理由的 Markdown 格式遵循 system prompt。
